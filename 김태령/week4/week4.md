# Spring_Basic_Week4

## 1. 정적 리소스와 컨트롤러의 우선순위
- **컨트롤러 우선 탐색**: 웹 브라우저에서 요청(`/`)이 들어왔을 때, 스프링 컨테이너에 매핑된 컨트롤러가 있다면 해당 컨트롤러가 정적 파일(`static/index.html`)보다 우선권을 가짐.
- `/` 경로를 처리하는 `HomeController`가 존재하면 정적 메인 화면 대신 컨트롤러가 지정한 HTML 템플릿이 렌더링됨.

---

## 2. GET 방식과 POST 방식의 역할 분리
동일한 URL 경로(`/members/new`)라도 HTTP 메소드에 따라 기능을 분리.

- **GET 요청 (`@GetMapping`)**:
  - 회원 등록 폼 화면을 조회할 때 사용됨.
  - 데이터를 단순히 불러와 사용자 화면에 보여주는 역할을 함.
- **POST 요청 (`@PostMapping`)**:
  - 폼에 입력된 실제 데이터를 서버로 전달하여 등록할 때 사용됨.
  - 데이터 저장 작업이 완료되면 보통 홈 화면(`redirect:/`) 등으로 **리다이렉트(Redirect)**시켜 중복 등록을 방지.

---

## 3. Model을 이용한 데이터 전달과 View 렌더링
- **Model 객체 역할**: 컨트롤러는 비즈니스 로직(`MemberService`)을 통해 조회한 데이터 목록을 `Model` 객체에 담아 뷰(View) 템플릿에 전달.
- **Thymeleaf 템플릿 엔진**:
  - `Model`에 담긴 데이터를 받아 동적으로 HTML을 생성.
  - `th:each`와 같은 루프 구문을 사용해 회원 목록 데이터를 루프 돌며 표(Table) 형태로 렌더링.
