## 웹이란?
- 처음에 웹은 정보 공유를 위해 만들어졌다.
- 하나의 정보를 게시판 처럼 올려놓으면 100명, 200명 다 확인할 수 있도록 한 것이 웹이였음.
-> 그러면 html로 만들 수 있는 거 아닌가요?

**html이란**
hyper text markup language
초능력이 있는 문자로 구조를 나타내는 언어
초능력이 있다는 건 순간이동을 시켜주는 즉, 링크를 걸어줄 수 있다는 것
이 링크를 나타낼 수 있는 문자로 구조를 나타냈다. 

예시
<h1>안녕하세요</h1>
<p>안녕하세요</p>
-> 제목, 내용 구분해서 작성하는 문법

결국 웹이란, 우리 모두를 위한 정보 공유의 **공간**

공간은 어디다? 
가상의 신경망 안에서, 전세계가 연결. = 인터넷(International Network)
cf. 웹은 인터넷 상의 공간일 뿐. (인터넷 네트워크에 공간 하나 딱 집어서 만든 거)

**이 인터넷 상에서 지켜야할 약속**
## HTTP
Hyper Text Transfer Protocol 
- 편지: 받는 사람, 목적, 내용, 보내는 사람. 
- 이처럼, 인터넷을 돌아다닐 때는 양식을 지켜야한다. 
- 예를 들어, 인터넷 중에 네이버에 가고 싶다 : http://naver.com
cf. 프로토콜 = 약속/규약


## 알쓸송잡
면접 준비, 취업 준비할 때 네트워크 책 사서 딸딸 외워야하나? 
아님. cs지식은 책 한 권을 씹어먹을 듯이 외우는 것이 중요한 것이 아님.
기본적인 지식은 알고 개발했을 것같은데, 이거 아나요? 
즉, 내가 포트폴리오에 제출한 프로젝트와 연관된 네트워크 지식, cs지식만 가져가면 됨.
예를 들어, 내가 웹 개발 프로젝트를 했다면, http관련 지식을 알아야하는 것임.


## 웹 역할 분리
한 명이 모든 걸 개발 -> 회원가입을 할 수 있음 -> 틀은 같은데 데이터만 다름 -> 화면 개발, 로직개발(데이터 연산) 분리. -> 프론트엔드, 백엔드.

## API란?

cf. Inter face: 서로 마주한다. 

API를 사이에 두고, 사용자와 데이터(서울교통공사데이터)가 마주보는 것. 

## REST API

cf. RESTful API : HTTP약속을 기가막히게 잘 지켰다.
